# model_agreement

This repositry contains the code for the paper titled "A Novel Technique for Robust Classification of Near-OOD Data".

Data Files:

There are four data files:

(1) UCI_cleveland.csv
(2) UCI_hungary.csv
(3) UCI_longbeach_va.csv
(4) UCI_switzerland.csv

The shell script run.sh is the drive code for the python file model_agreement.py. This pyhon file contains the main code. 

table_results.ipynb contains the code to generate the results for the tables used in the paper.

plot_results.ipynb contains the code to generate various plots.
